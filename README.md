# 📚 Parlor Vision — ИИ-репетитор английского языка

## 🎯 Что это такое?

Parlor Vision — это локальный ИИ-репетитор, который помогает выучить **3000 самых частотных слов английского языка** через голосовое общение. Всё работает на вашем компьютере — **без интернета**, **без подписок**, **без отправки данных в облако**.

---

## ⚡ Как это работает

| Компонент                 | Что делает                                            |
| :------------------------ | :---------------------------------------------------- |
| **Whisper (STT)**         | Распознаёт вашу речь и превращает её в текст          |
| **Gemma 4 / Llama (LLM)** | Генерирует ответы, объясняет слова, исправляет ошибки |
| **Edge-TTS (TTS)**        | Озвучивает ответы голосом                             |
| **Прогресс**              | Отслеживает выученные слова и их уровень (A1/A2/B1)   |

---

## 🎓 Программа обучения

| Уровень | Количество слов | Порог выученности     | Описание                                   |
| :------ | :-------------- | :-------------------- | :----------------------------------------- |
| **A1**  | 300             | 3 правильных ответа   | Начальный уровень: самые базовые слова     |
| **A2**  | 1000            | 8 правильных ответов  | Элементарный уровень: повседневное общение |
| **B1**  | 3000            | 12 правильных ответов | Средний уровень: свободное общение         |

### 📌 Пояснение к таблице

- **Порог выученности** — количество правильных ответов, после которых слово считается выученным
- **Слова A1** входят в список A2, слова A2 входят в список B1 (накопительная система)
- **Цель** — выучить все 3000 слов для достижения уровня B1

---

## 🗣️ Как проходит урок

1. **Вы говорите** в микрофон (или вводите текст в чат)
2. **Система распознаёт** вашу речь
3. **ИИ отвечает** голосом и текстом:
   - Объясняет новые слова
   - Исправляет ошибки
   - Задаёт вопросы
   - Хвалит за прогресс
4. **Выученные слова** сохраняются в прогресс
5. **Через 2-3 вопроса** — повторение ранее выученных слов

## ⚠️ Важный нюанс: Модель НЕ ДОЛЖНА "думать"

**Для корректной работы репетитора языковая модель НЕ должна использовать режим "мышления" (reasoning/thinking).**

### Почему это важно:

- В режиме мышления модель возвращает пустой ответ, а не финальный JSON
- Это приводит к ошибкам парсинга и пустым сообщениям
- Для нашего репетитора нужны быстрые, прямые ответы, а не рассуждения

### Как отключить мышление Для LM Studio:

1. Создайте копию модели с отключённым мышлением через model.yaml:

```yaml
customFields:
  - key: enableThinking
    defaultValue: false
metadataOverrides:
  reasoning: false
```

2. Проверьте в интерфейсе LM Studio, что в настройках модели (Advanced → Reasoning Parsing) мышление отключено.

# 📚 Инструкция по запуску

## 🖥️ Системные требования

- **ОС:** Windows 10/11, Linux или macOS
- **Python:** 3.10 или выше
- **RAM:** 8 ГБ (рекомендуется 16 ГБ)
- **GPU:** NVIDIA с 4+ ГБ VRAM (рекомендуется) или CPU (медленнее)
- **Диск:** 20+ ГБ свободного места

---

## Компоненты для установки

1. **Python 3.10+** — [Скачать](https://www.python.org/downloads/)
2. **Git** — [Скачать](https://git-scm.com/downloads)
3. **Ollama** или **LM Studio** — выбор бэкенда

---

## ⚙️ Шаг 1: Установка бэкенда

### Вариант A: Ollama (рекомендуется для простоты)

**Windows:**

1. Скачайте установщик с [ollama.com](https://ollama.com/download/windows)
2. Запустите `OllamaSetup.exe` и следуйте инструкциям
3. После установки Ollama запустится автоматически (иконка в трее)

**Проверка:**

```bash
ollama --version

```

### Вариант B: LM Studio (более гибкий)

1. Скачайте LM Studio с [lmstudio.ai](https://lmstudio.ai/)
2. Установите и запустите
3. Скачайте модель (например, google/gemma-4-e4b)
4. Перейдите на вкладку "Developer" и включите сервер (Start Server)

### 🤖 Шаг 2: Скачивание языковой модели

```
# Скачать модель Gemma 4 E2B (~5 ГБ)
ollama pull gemma4:e2b

# Или E4B (более качественная, ~8 ГБ)
ollama pull gemma4:e4b

# Проверка установленных моделей:
ollama list

```

### 📦 Шаг 5: Установка зависимостей

```
# Установить uv (быстрый менеджер пакетов)
pip install uv

# Установить зависимости проекта
uv pip install -e .

```

### ⚙️ Шаг 6: Настройка .env файла

Создайте файл .env в папке src/:

```env
# Ollama
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=gemma4:e2b

# STT (распознавание речи)
STT_BACKEND=whisper
WHISPER_MODEL=large-v3-turbo
WHISPER_DEVICE=cuda
WHISPER_COMPUTE_TYPE=float16

# Сервер
PORT=8000

```

### 🚀 Шаг 7: Запуск сервера

```
cd src

uv run python server.py
```

### Шаг 8: Открытие в браузере

Откройте браузер и перейдите по адресу:

```
http://localhost:8000
```
